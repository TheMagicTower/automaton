automaton — 모드·권한 시스템 (섹션 2/5)

모드 = 툴셋 + 프롬프트 + 권한 프로파일의 조합. 권한은 언제나 결정론적 규칙이 판정.

초기 3개 모드

모드툴셋자율 수준성격(프롬프트)
⚙ codefs·shell·edit·grep·lsp자율 (위험 셸만 검사)정확한 엔지니어
🔭 maccapture·AX·click·type + 제한 셸위험 동작 승인신중한 조작수
📖 chat읽기 전용 (grep·read)완전 자율 (부작용 없음)대화 파트너

모드 전환: 사용자 명시(단축키·명령) 또는 에이전트 요청 → 전환 자체도 승인 이벤트. 세션 컨텍스트는 유지, 툴셋만 스왑.

ALLOW — 읽기류·모드 내 안전 쓰기 → 즉시 실행

모든 결정(allow 포함)은 감사 로그 + Decision Journal에 기록 → Apprentice 학습 데이터

위험 분류 규칙 (초기값)

  • ALLOW: 화면 캡처, AX 트리 읽기, 파일 읽기·검색, code 모드의 편집·빌드
  • ASK: 셸 실행(mac 모드), 파일 삭제/이동, 시스템 설정 변경, 미등록 앱 클릭/타이핑, 모드 전환, 큰 금액·외부 전송 전 전부
  • DENY: 화이트리스트 밖 민감 영역(비밀번호 필드·Banking 앱 등), 설정된 금지 목록
  • 항상 허용 선택 시 해당 규칙만 정책 파일에 추가 (감사 가능, 언제든 철회)
