automaton — 메모리·스킬 시스템 (섹션 3/5)

스킬 = 명시적 절차 기억(어떻게), 메모리 = 사실·선호(무엇을), Apprentice = 암시적 선호 학습(무엇을 좋아하는지).

메모리 3계층
① 세션
현재 대화·툴 결과
압축 요약으로 관리
② 작업
세션 요약 보관
FTS5 + 벡터 검색
③ 장기 (큐레이션)
에이전트가 사실 제안
→ 내가 승인해 저장
단일 SQLite (sessions · summaries · facts · decisions) + 임베딩은 sqlite-vec. 세션 시작 시 관련 기억 top-k 자동 주입 + memory.search 툴로 명시 검색.

장기 메모리 큐레이션 (Hermes 패턴 차용)

  • 세션 종료/유휴 시 에이전트가 "기억할 만한 것"을 제안 (예: "선호: PR 생성 전 항상 로컬 테스트")
  • SwiftUI에서 승인/거절 → 승인된 것만 facts 테이블로 → 오염 방지
  • 거절 이력도 Apprentice가 학습 (같은 제안 반복 방지)

스킬 시스템 (agentskills.io 호환)

  • 스킬 = 폴더 + SKILL.md(이름·설명·사용시점) + 선택적 스크립트/참고문서
  • 점진적 로딩: 시스템 프롬프트엔 이름·설명만 → 필요할 때 본문 로드 (토큰 효율, 이 하네스와 동일 패턴)
  • 위치: ~/.config/automaton/skills/ (전역) + 프로젝트 .automaton/skills/. 모드 스코프 가능(mac 전용 스킬 등)
  • 자기개선 루프: 복잡 작업 성공 후 에이전트가 절차를 스킬로 제안 → 승인하면 저장 (Hermes의 "grows with you")
